<Subtitle>Composition root for the interactive CV landing page.</Subtitle>
<Description>
The layout component assembles the top bar, hero, overview cards, technology explorer,
experience list and sidebar into one SPA screen. It owns only presentation state such as
theme switching and selected technology. Business data is expected to be prepared outside.
</Description>

## Responsibilities

- Compose all visible sections of the CV homepage.
- Keep local UI state for theme and selected technology.
- Derive overview metrics and filtered section data from CV input.

## Non-goals

- It is not a generic page shell.
- It should not become the home for copy constants or raw data fetching.
